# notes/

Working notes live here: feature specs, investigation notes, incident
write-ups, and the rationale behind fixes. Committing them alongside the code
keeps the reasoning reviewable, not just the diff.

Suggested files, not enforced:

- `<feature>-spec.md` for planned work
- `incident-<topic>.md` for investigations
- `data-flow-map.md` for tracing how values move between layers
